# Exercise 1 – Matrix Size and Entries

## Question

Given the matrices:

\[
A=\begin{pmatrix}2&-1&3\\0&4&5\end{pmatrix},
\quad
B=\begin{pmatrix}1&0\\-2&3\\4&1\end{pmatrix}
\]

1. Find the sizes of A and B.
2. Find \(a_{12}\), \(a_{23}\), \(b_{21}\) and \(b_{32}\).
3. Write the second row of A and the first column of B as vectors.
4. Check if \(b_{32}=1\).

## Solution

**1. Matrix sizes**

Matrix A has 2 rows and 3 columns, so its size is \(2\times3\).

Matrix B has 3 rows and 2 columns, so its size is \(3\times2\).

**2. Matrix elements**

\[
a_{12}=-1,\quad a_{23}=5
\]

\[
b_{21}=-2,\quad b_{32}=1
\]

**3. Rows and columns**

The second row of A is:

\[
(0,\ 4,\ 5)
\]

The first column of B is:

\[
\begin{pmatrix}1\\-2\\4\end{pmatrix}
\]

**4. Verification**

The element in the third row and second column of B is 1.

\[
b_{32}=1
\]

So the condition is correct.

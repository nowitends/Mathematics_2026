# Exercise 6 - Parameter and Invertibility

## Question

Given:

\[
A(t)=\begin{pmatrix}
t&1\\
2&t
\end{pmatrix}
\]

Find all values of t for which the matrix is not invertible. Explain your answer.

## Solution

A matrix is not invertible when its determinant is zero.

\[
\det(A(t))=t\cdot t-1\cdot2
\]

\[
t^2-2=0
\]

\[
t^2=2
\]

\[
t=\pm\sqrt{2}
\]

Therefore, the matrix is not invertible for:

\[
t=\sqrt{2}\quad\text{or}\quad t=-\sqrt{2}
\]

At these values, the determinant is zero.

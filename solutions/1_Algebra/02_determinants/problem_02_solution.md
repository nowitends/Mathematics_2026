# Exercise 2 - Determinant of a 3x3 Matrix

## Question

Calculate the determinant of the matrix.

\[
A=\begin{pmatrix}
1&2&-1\\
0&3&4\\
2&1&5
\end{pmatrix}
\]

## Solution

Using Sarrus' rule:

\[
\det(A)=1(3)(5)+2(4)(2)+(-1)(0)(1)
\]
\[
- [(-1)(3)(2)+1(4)(1)+2(0)(5)]
\]

\[
=15+16-(-6+4)=33
\]

Therefore, \(\det(A)=33\).
